# MERN Stack Todo Application

A full-stack todo application built with MongoDB, Express.js, React, and Node.js (MERN stack), featuring CRUD operations and Ant Design UI.

## Features
- Create, Read, Update, Delete todos
- Filter todos by status (pending, in-progress, completed)
- Responsive Ant Design UI
- Context API for state management
- RESTful API backend

## Technologies
- **Frontend**: React, Ant Design, Vite, Axios  
- **Backend**: Node.js, Express.js, MongoDB, Mongoose

## Prerequisites
- Node.js (v18+)
- MongoDB (local instance or MongoDB Atlas)
- Git
